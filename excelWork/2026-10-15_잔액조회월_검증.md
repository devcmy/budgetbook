# 잔액 조회월 선택 기능

아래는 기능 도입 당시 검증입니다. 현재 잔액은 가족통장 원금 61,000원 회수 후 WRAP 6,685,466원이며, 최신 수치·검증은 [생신 정산·명칭 수정](2026-10-15_생신정산_검증.md)을 따릅니다. 조회월 선택 기능은 유지합니다.

작업일: 2026-10-15. 기준본: [테트리스_가계부_2026_고도화.xlsm](테트리스_가계부_2026_고도화.xlsm).

## 사용 방법

1. 잔액 탭의 노란색 **조회월(B3)**을 클릭하고 목록에서 3~12월을 고릅니다. 기존 내역 월과 같은 데이터 유효성 검사 드롭다운입니다.
2. 위쪽 전월말, 월 입출금·이체, 계정별 WRAP 잔액, WRAP 잔액 합계와 목적자금 합계가 선택한 달 기준으로 바뀝니다. 기본 선택은 기존처럼 2026년 10월입니다.
3. 아래쪽 **내역 월(B35)**은 거래내역 표시용으로 별도 유지합니다. 위쪽 조회월을 바꾼다고 아래 내역 월을 덮어쓰지 않습니다.

조회월의 실제 값은 선택한 달의 1일입니다. 목록은 기존 월별 비교표의 날짜인 `C21:L21`을 사용하므로 문자열 월과 날짜 비교가 섞이지 않습니다. 빈 값이나 목록 밖 입력에는 중지 경고를 표시합니다.

과거 달은 월말 기록 기준, 최신 거래가 있는 달은 입력된 거래 기준으로 표시합니다. 11~12월은 아직 거래를 입력하지 않았으므로 **이월 잔액**이라고 표시합니다. 계획된 수입·지출을 자동 반영한 예상 잔액이나 은행 앱 실시간 잔액이 아닙니다. 현재 자료의 시작이 3월이므로 기존 내역 월과 동일하게 3~12월을 제공합니다.

## 연결 보정

기존 잔액 요약은 이미 B3를 참조했습니다. 조회월에 드롭다운을 추가하고 자동 계산을 설정했습니다. 상단 안내는 고정된 10월 문구 대신 선택월·기록 상태를 표시합니다.

월별 비교표를 선택월까지 숨기던 조건은 **최신 WRAP 원장 기록월까지 표시**하도록 바꿨습니다. 과거 월을 조회해도 3~9월 원본 대조와 10월 검증이 유지되도록 하기 위해서입니다.

- `검증!I168`: 화면의 전월말 대신 고정된 9월 말 합계 `잔액!I32`를 참조합니다.
- `검증!I175`: 화면의 조회월 합계 대신 고정된 10월 합계 `잔액!J32`와 비교합니다.
- `예비비!L72:L76`: 잔액 화면의 조회월이 아니라 원장의 최신 기록월을 유효 범위로 삼습니다. 예비비 자체의 기준월은 변경하지 않습니다.
- 월별 비교표의 미입력 미래 월은 계속 빈칸으로 둡니다. 미래 월을 명시적으로 조회할 때만 위쪽에 이월액을 보여줍니다.

RAW 거래·분류·대납 상태·원장 입력·월간 수입/지출·테트리스 색상은 변경하지 않았습니다. 10월 WRAP 잔액 6,624,466원, 본인 생활비 1,299,740원, 테트리스 1,321,000원, 미회수 대납금 103,600원을 유지합니다.

## 검증 방법

[balance_month_selector.py](scripts/balance_month_selector.py)로 3~12월을 각각 선택한 임시 파일을 만들고 재계산합니다. 원장 날짜·유효금액·보낸 계정·받은 계정·거래 종류를 Python으로 별도 합산하여 `B7:G16`과 `G17` 총 61개 셀을 월별로 대조합니다. 각 월마다 기존 Boolean 검증값, 다른 탭의 재무값 유지, 수식 오류도 확인합니다.

재계산은 VBA를 제거한 **임시 XLSX**에서만 수행하고, 최종본에는 결과 캐시만 옮깁니다. 원본 XLSM의 VBA·버튼/그림·관계 파일·스타일은 다시 생성하지 않습니다. 최종 저장 시 기본 조회월은 10월입니다.

자동 검증 결과는 [balance_month_selector_validation.json](balance_month_selector_validation.json), 현재 기준본 수치와 해시는 [audit.json](audit.json)에 기록합니다. Excel 데스크톱에서 드롭다운을 실제 클릭하거나 VBA를 실행한 테스트는 아니며, OOXML 설정 검사와 LibreOffice 재계산을 통한 검증입니다.

검증 결과: 10개월 × 잔액 61개 셀, 각 월의 기존 Boolean 검증값 318개 유지, 수식 오류 0건입니다. 다른 탭의 재무값·모든 기존 셀 스타일·병합 범위·VBA/버튼/바이너리 파일이 유지됐습니다. RAW 143건 대조와 생활비·테트리스 색상 합계 등 기존 `verify_20261015.py` 검증도 다시 통과했습니다.
