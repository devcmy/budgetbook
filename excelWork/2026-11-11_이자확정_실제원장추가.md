# 11/11 이자수익 확정과 실제 원장 반영

## 사용 방식

사용자는 이자를 매일 기록하지 않고 가계부 작성 시 누계로 입력합니다. 이번에는 기존 WRAP 이자 거래ID2667을 **11/11 누계 이자수익 한 건 13,964원**으로 갱신했습니다. 기존 12,802원과 오늘 이자를 각각 다시 추가하지 않았습니다. 직전 정산 이후 발생한 세금·수수료 차감 후 수익을 작성한 달의 수입으로 인식합니다.

다음 작성 시에는 이번 정산 이후 발생한 이자수익만 새 한 건으로 입력합니다. 이번 누계와 겹치는 기간을 다시 더하지 않습니다. RAW 메모는 설명용이며 분류·집계 조건으로 쓰지 않습니다.

## WRAP 잔액

거래내역증명서의 11/11 최종 잔액은 **8,288,985원**입니다. 잔액 탭의 WRAP 총액과 일치하며, 생활비 6,138,985원 + 목적자금 2,150,000원으로 구성됩니다. 조회월은 잔액·예비비 모두 11월로 맞췄습니다.

확인 근거:

- 10/13 정산 후 실제/작업 파일 잔액: 6,624,466원으로 일치.
- 이후 11/11까지 외부 입출금 순증가: 1,650,555원.
- 이후 세금·수수료 차감 후 운용수익: 13,964원.
- `6,624,466 + 1,650,555 + 13,964 = 8,288,985원`.

사용자가 확인한 11/10 잔액 8,288,458원은 증명서와 일치합니다. 다만 이번 저장소의 수정 전 작업 파일은 8,287,823원이었습니다. 이 635원 차이를 사용자의 실제 잔액 부족으로 취급하지 않습니다. 이번에는 **저장소 작업 파일의 기존 이자 한 건**을 증명서 기준 누계로 갱신했으며, 임의의 635원 보정 거래를 별도로 만들지 않았습니다.

이전 ‘원인 미확인/이자 확정 아님’ 안내는 현재 파일에서 이자수익 누계 입력 안내로 대체했습니다. 이전 분석 문서와 백업은 당시 이력입니다.
