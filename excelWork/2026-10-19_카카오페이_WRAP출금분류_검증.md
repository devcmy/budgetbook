# 카카오페이 충전의 WRAP 출금 분류 수정

후속 RAW 갱신: 이 문서는 출금 재분류 직후의 이력입니다. 이후 보증보험료 110,075원이 추가되어 현재 입금·사용은 5건, WRAP 총액은 6,559,691원입니다. 카카오페이 출금 분류와 다른 이체 12건은 유지합니다. 최신 수치·해시는 [10/19 RAW 반영·검증](2026-10-19_RAW반영_검증.md) 및 `raw_update_20261019_validation.json`을 따릅니다.

2026-10-19(Asia/Seoul). 사용자가 원한 것은 이름만 ‘외부출금’으로 바꾸는 것이 아니라 **WRAP 잔액 탭에서 출금으로 처리하고 왼쪽 ‘WRAP 입금·사용’에 표시하는 것**입니다. 앞선 명칭 수정만으로는 이를 충족하지 못해 실제 분류를 정정했습니다. 변경 전 파일·문서는 [history/2026-10-19/03](history/2026-10-19/03/SNAPSHOT.md)에 보관했습니다.

## 실제 수정

원장 248행의 `B248`을 **출금**, `D248`을 **지출**, `L248`을 **WRAP입출금**으로 바꾸고 메모에 WRAP 관리상 출금이라는 기준을 명시했습니다. 금액 15,700원·날짜·실제 보내는 계좌 WRAP·받는 계좌 카카오페이머니·RAW 2475행 연결은 그대로입니다.

조회 분류 `P/Q`, 받는 계정 `S`, 부호 있는 표시액 `T`는 기존 **공유 수식을 그대로 유지**하여 자동 계산합니다. 이름만 바꾸거나 수식 칸을 고정값으로 덮지 않습니다. 조회 순서·상단 및 하단 원장 표시 캐시도 재계산합니다.

| 항목 | 이전 | 수정 후 |
|---|---|---|
| WRAP 원장 유형 | 이체 | 출금 |
| 왼쪽 입금·사용 | 3건, 충전 제외 | **4건, 충전 −15,700원 표시** |
| 오른쪽 계좌이체 | 13건, 충전 포함 | **12건, 충전 제외** |

| WRAP 생활비 잔액 | 4,519,766 | 4,519,766 |
| WRAP 총액 | 6,669,766 | 6,669,766 |

같은 15,700원이 ‘이체 보냄’에서 ‘사용·출금’으로 옮겨지므로 다시 차감되지 않습니다. 다른 이체 12건의 입력 내용은 그대로이며, 특히 임시보관→생활비 61,000원도 이체 표에 유지합니다. 조회표의 순번·표시 위치가 당겨지는 것은 정상적인 재계산입니다.

## RAW와 소비는 별도 보존

RAW는 실제 발생 기록이므로 충전 2475행의 **이체지출·내부이체·15,700원**을 그대로 둡니다. ‘WRAP 출금으로 분류’한다는 것은 잔액 관리·표시상의 처리이며 충전을 또 하나의 소비로 만들지 않습니다.

- 더치 구매 17,000원 = 충전 15,700원 + 회수한 양배추 대리구매 금액 1,300원.
- 실제 구매 소비 17,000원은 달력·테트리스에 이미 1회 포함됩니다.
- 추가 실지출 표는 실지출 17,000원·이미 집계 17,000원·추가 합산 0원입니다.
- 본인 생활비 1,476,900원·테트리스 1,501,000원·미회수 철도 대납 103,600원·생신 예비비 사용 239,000원은 그대로입니다.
