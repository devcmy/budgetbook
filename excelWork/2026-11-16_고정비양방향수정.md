# 월별 고정비 ↔ RAW 양방향 수정

PC용 **Microsoft 365 또는 Excel 2021 이상**에서 매크로를 사용하면, 각 월 고정비의 **O열 청구액·V열 메모**를 수정해 연결된 RAW에 반영할 수 있습니다. RAW 수정도 기존처럼 월별 고정비에 반영됩니다. 별도 화면으로 이동하지 않고 연결된 거래를 수정하도록 만들었습니다.

## 사용 방법

| 월별 고정비에서 하는 작업 | 처리 |
| --- | --- |
| 연결된 RAW가 1건인 청구액 수정 | 같은 거래의 금액에 반영하고 월별 계산 수식을 복원 |
| 여러 RAW가 합쳐진 청구액 수정 | 거래ID·날짜·내용·금액을 보고 수정할 거래 선택. 월 합계의 변경 차액을 그 거래에 반영 |
| 메모 수정·삭제 | 해당 RAW의 I열 메모 수정·삭제. 합산 메모는 거래를 선택해 그 거래만 변경 |
| 연결된 실제 RAW가 없는 청구액 입력 | 실제 거래 연결·등록, 예정액 수정, 취소 중 선택 |
| 기존 거래 연결 | 같은 월의 본인 지출 거래ID를 골라 고정비와 연결. 이미 다른 고정비에 연결된 거래는 중복 연결하지 않음 |
| 새 실제 거래 등록 | 실제 거래일·결제 카드/계좌·내용을 입력해 RAW 빈 행에 1건 등록. 해당 월 실제 고정비로 반영 |
| 예정액 수정 | 11·12월 AB 예정 입력에 반영. 실제 RAW 거래는 만들지 않음 |

예를 들어 청구액 5만원이 RAW 2만원+3만원으로 구성돼 있다면, 5만5천원으로 수정하고 3만원 거래를 선택했을 때 그 거래만 3만5천원으로 바뀝니다. 다른 거래 금액을 덮어쓰지 않습니다.

본인부담이 전체 결제액과 같으면 금액과 본인부담을 함께 수정합니다. 일부만 본인부담인 거래는 전체 결제액을 보존하고 본인부담만 수정합니다. RAW G열의 고정비 금액을 한 건 직접 수정하는 경우에도 전액 본인부담 연결과 CMA 원장을 함께 갱신합니다.

청구액을 지우면 0원 정정으로 처리하며 RAW 거래ID는 유지합니다. 메모를 지우면 RAW 메모도 지워지고 각 월·계산기·연결된 원장 표시도 함께 비워집니다. 여러 칸의 동시 붙여넣기는 월별 편집에서 되돌리고 한 칸씩 입력하도록 안내합니다.

## 입력과 계산의 구분

양방향 원장 수정 대상은 **O 청구액·V RAW 메모**입니다. P 환급·할인과 Q 실지출 등 기존 계산 관계, 표의 항목명·결제일 안내·예정 입력은 별도 의미를 유지합니다. 1~9월 숨김도 유지합니다.

이전 월에 보존한 수기 이월·청구/실제 차이는 유지합니다. 기존 RAW가 있는 항목에서는 월 합계의 변경 차액을 연결 거래에 반영합니다. 실제 RAW가 없던 항목에 거래를 새로 연결할 때는 기존 예정·참고액과 중복 합산하지 않습니다.

매크로가 꺼져 있거나 Excel 웹에서 열었을 때는 O·V 계산 수식을 보호합니다. PC에서 매크로를 사용하면 편집이 열리며, 저장할 때는 연결 수식을 보호한 상태로 저장합니다. 예정 입력은 별도로 사용할 수 있습니다. 메모 집계는 직접 편집할 수 있도록 단일 결과의 FILTER/TEXTJOIN 수식으로 바꿨습니다.

## CMA 잔액

연결된 CMA 지출의 금액을 수정하면 같은 RAW 거래ID로 연결된 잔액 원장 금액도 반영합니다. 새 CMA 고정비는 RAW 1건과 현금 원장 1건을 만들고, 카드 결제는 실제 은행 출금으로 추가하지 않습니다. 분할·합산된 현금 원장처럼 자동으로 판단할 수 없는 연결은 변경을 되돌리고 원장 확인을 안내합니다.

현재 파일의 실제 거래는 변경하지 않았습니다. RAW 2,741건, 11월 달력 1,262,901원·테트리스 1,284,000원·최종 사용 1,889,416원, 10월 CMA 8,434,741원·생활비 6,084,741원·목적자금 2,350,000원은 유지합니다. 11·12월 날짜순 계산기와 10월 적립 20만원도 그대로입니다.

## 재분류는 무엇을 기준으로 하나

RAW D열 `분류`는 원본의 식비·교통·경조사 같은 분류입니다. J열 `재분류`는 그 거래를 가계부에서 **어떻게 집계할지** 정합니다.

- 기본 판단에는 수입/지출/이체 유형, 원본 분류, 결제처·거래내용, 계좌, 기존에 확정한 처리 기준을 사용합니다.
- 일반 식비는 변동비, 확인된 정기요금·할부는 고정비, 공동계좌의 공동 지출은 공금, 주택청약 등은 자산형성으로 구분합니다.
- 원장 반영 과정에서 경조사 원본은 경조·선물, 가전 원본은 일회성전자, 만남 소분류는 약속·만남 등으로 지정한 값도 있습니다. 따라서 J에는 자동 기본값과 직접 지정된 값이 함께 있습니다.
- J에 직접 지정한 값이 자동 기본분류보다 우선합니다. 직접 지정된 행에서는 원본 분류를 바꿔도 J가 자동으로 바뀌지 않습니다.
- **메모 I열은 분류 기준으로 사용하지 않습니다.** 대납 등 확정 사항은 J·본인부담·결제구분에 따로 기록합니다. 경조·선물로 분류했다는 이유만으로 특정 예비비 잔액을 차감하지 않습니다.

예를 들어 버즈 할부는 원본 분류가 경조사여도 고정비로 집계합니다. 쿠팡 C타입 케이블은 원본의 가전 분류를 일회성전자로 지정한 경우입니다.

## 검증과 범위

- 초기 RAW 값과 12개월 고정비·월별 합계·메모·계산기·잔액·예비비를 비교해 기존 값 보존을 확인했습니다.
- 기존 검색 매크로 등 13개 모듈의 소스는 그대로 보존하고, 통합문서 이벤트 추가 및 BBFixed 모듈을 설치했습니다. 원래 컨트롤·그림·관계 파일과 기존 스타일 ID도 보존했습니다.
- 계산 사본에 단일 금액 수정, 합산 항목의 선택 거래 변경, 일부 본인부담, 메모 변경·삭제, 기존 RAW 연결, 새 실제 거래, 예정액만 수정, 기존·신규 CMA 출금과 취소에 해당하는 입력을 넣어 월별·원장 결과를 대조했습니다.
- 자동 테스트 194개, 수식 오류 0, XML/패키지 오류 0입니다. 계산 도구가 메모 줄바꿈을 정규화하는 부분은 원본 I열에서 표시 캐시를 복원했습니다.

**Microsoft Excel의 VBA 이벤트를 실제 실행한 검사는 하지 못했습니다.** 검증 범위는 VBA 소스·이벤트 연결·보호 설정 검사와 독립적인 RAW 수정/재계산 사본입니다. 파일에 현재 거래의 테스트 값을 남기지 않았습니다.
