# 11월 RAW 추가와 WRAP 12,802원 차액 검토

## 결론

12,802원은 사용자가 실제 WRAP 잔액에 맞추려고 입력한 **원인 미확인 차액**입니다. 실제 이자 입금으로 확인된 금액이 아니므로 확정 이자로 설명하면 안 됩니다.

제공된 9월 이후 WRAP 거래와 기존 잔액 기록을 대조했으나, 이 차액을 설명하는 누락 입금·중복 출금을 특정하지 못했습니다. 이것은 은행 원장에 누락이 전혀 없다는 증명이 아닙니다. RAW 자체에 기록되지 않은 거래, 원금/평가액/출금가능액의 비교 기준 차이, 더 이전 기초잔액 차이는 현재 자료만으로 확정할 수 없습니다. 이자수익이라는 추정도 확정하지 않습니다.

## 9월: 별도 누락으로 보였던 항목의 재구성

9월 WRAP RAW는 23건입니다. 과거 잔액표는 일부를 월 단위 합계로 저장했고, RAW 입력월과 잔액표의 정산월이 다른 건도 있습니다.

| 9/1 카카오페이→WRAP 814,000원, ID2088 | 8월 여행 정산, 195행 | 동일 금액이 이미 존재 |
| 9/1 WRAP 이자 4,467원, ID2087 | 8월 CMA 이자, 192행 | 동일 금액이 이미 존재 |

| 9/27 입출금 8건 | 9월 월급 후 정산 2,082,285원, 214행 | 아래 순액 계산과 정확히 일치 |
| 9/13 5개 은행 이체 | 카드값 합계 4,848,153원, 229행 | 합계와 정확히 일치 |

월급 후 정산 재구성:

`국민→WRAP 2,465,050 + 신한→WRAP 51,312 + 이자 5,923 − 약속 정산 150,000 − 희망두배 150,000 − 청약 20,000 − 증권 60,000 − 증권 60,000 = 2,082,285원`

따라서 5,923원은 이자라는 독립 행이 없다는 이유만으로 다시 더하면 안 됩니다. 나머지 7개 RAW도 해당 원장 금액과 일치합니다. 23건 전체를 중복 사용하지 않고 금액으로 재구성했습니다.

9월 RAW 순증감은 −2,149,649원, 기존 9월 원장 순증감은 −2,957,116원입니다. 겉으로 보이는 807,467원 차이는 `814,000 + 4,467 − 11,000`과 정확히 같습니다. 이를 반영한 재구성 잔차는 **0원**입니다. 과거 거래의 실제 일시/은행 거래ID가 남아 있지 않으므로 동일 거래의 은행 증빙 확인과는 구분합니다. 과거 잔액과 날짜는 이번에 수정하지 않았습니다.

11/2 첨부했던 9월 재추출본의 WRAP 23건도 현재 RAW와 같습니다. 당시 보류된 다른 9월 차이 목록에는 WRAP 직접 입출금이 없습니다.

참고: 9월 외부→WRAP 4건(ID2088·2090·2293·2298)의 RAW 방향 보조열에는 출금으로 보이는 과거 표시 문제가 있습니다. 이 기간의 실제 잔액 계산은 해당 보조열이 아니라 위 월별 원장을 사용하므로, 이 표시가 12,802원을 차감한 원인은 아닙니다. 이번 진단에서 과거 수식을 변경하지 않았습니다.

## 10월과 11월

10월 WRAP RAW 24건은 원장 연결 ID·금액·일시·입출금 방향을 대조했으며 연결 누락/중복이 없습니다. 내부 목적계정 이동 61,000원은 은행 입출금이 아니므로 별도로 구분했습니다.

`9월말 원장 8,538,603 + 10월 입금 3,472,652 − 10월 출금 3,576,514 = 10월말 8,434,741원`

이번 11월 자료의 WRAP 거래:

| 기록 | WRAP 증감 | 처리 |
| --- | ---: | --- |
| 11/9 신한은행 이체 | −12,420 | 후속 MONA 통신비 출금과 WRAP에서 중복 차감하지 않음 |
| 11/10 중앙제육식당 | −10,000 | 현금 소비와 WRAP 출금에 각각 1회 연결 |
| 11/10 모두의카드 정산 | −137,300 | 실제 청구월 고정비와 WRAP 출금에 각각 1회 연결 |
| 11/10 명목상 이자 입력 | +12,802 | 실제 이자로 검증되지 않은 사용자 잔액 맞춤 입력 |

현재 엑셀 기초잔액을 기준으로 재계산하면 차액 입력 전 **8,275,021원**, 입력 포함 **8,287,823원**입니다. 이는 파일 내 계산 결과이지, 실제 은행 잔액 화면을 별도로 확인한 숫자는 아닙니다. 사용자는 차액을 추가하여 실제 WRAP 잔액과 일치시켰다고 확인했습니다.

원본의 12,802원 금액·수입 유형·‘미래에셋 WRAP 이자’ 내용은 임의 수정하지 않았습니다. 그래서 현재 기타수입 계산 12,890원에는 이 미확정 차액이 포함되어 있고, 이를 제외한 기타수입은 88원입니다. 잔액 원장 내용·11월 안내·사용안내에 이자 확정이 아닌 차액임을 표시했습니다. 분류 정정은 원인이 밝혀지거나 사용자가 처리 방식을 정할 때 진행합니다.
