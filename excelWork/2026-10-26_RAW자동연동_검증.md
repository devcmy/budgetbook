# RAW 입력 → 월간·계산기 자동 연동

변경일: 2026-10-26. 실제 거래 기준일: 2026-10-19. 운영 파일은 같은 폴더의 `테트리스_가계부_2026_고도화.xlsm`입니다.

## 사용하는 방법

1. `RAW` 탭에서 필터를 전체로 해제합니다. 오른쪽 안내의 **다음 입력 위치**를 누르면 빈 행으로 이동합니다. 현재 첫 빈 행은 2494행입니다.
2. **A열에 일시, C~I열에 원본 거래**를 값으로 붙여넣습니다. 원본 내보내기의 일시는 A열, 자산~추가입력 7개 항목은 C~I열에 붙입니다. B열은 따로 입력하지 않습니다.
3. B열 머리글 **▼**에서 원하는 월을 선택합니다. 월 필터는 RAW의 보기만 바꾸며 다른 월의 계산 결과를 바꾸지 않습니다.
4. 해당 월 달력·월 합계·월별 계산기 숫자와 색상이 갱신됩니다. Calculate 버튼이나 매크로 실행은 필요 없습니다. Excel 계산 옵션은 **자동**으로 사용합니다.

| 열 | 역할 |
|---|---|
| A | 거래 일시 입력 |
| B | 일시에서 자동 계산한 월 · 월별 필터 |
| C~I | 자산 / 분류 / 소분류 / 내용 / 금액 / 수입·지출 / 추가입력 |
| J | 자동 분류. 특수한 거래는 드롭다운으로 재분류 가능 |
| K | 자동 본인부담액. 공동 부담 등 필요한 경우 직접 수정 가능 |
| L | 자동 결제 구분. 본인·공동·정산대기 등 필요한 경우 수정 가능 |
| M | 비고 입력 |
| N | 입력 오류·중복·별도 원장 등록 안내 |

초록 칸은 자동 계산 칸, 입력 영역은 옅은 줄무늬입니다. 일시·월과 머리글을 고정하고, 금액은 천 단위 구분·음수 빨강으로 표시했습니다. 계산 보조열은 숨겼습니다. 잘못된 일시·금액은 빨강, 중복 확인은 주황, 새 WRAP 거래의 별도 원장 등록 안내는 노랑입니다.

기존 2,492건에 더해 **1,508건을 추가할 수 있는 4,000건 입력 공간**을 준비했습니다. 기존 원장에 RAW 행번호 연결이 있으므로 **정렬·행 삭제·행 삽입과 계산용 칸은 보호**하고 거래 입력과 필터는 허용했습니다. 암호는 없습니다. 공간을 모두 쓰면 `검토 → 시트 보호 해제` 후 표 범위를 늘려야 합니다. 행 재정렬·삭제 대신 기존 입력 값을 수정하세요. 표 밖 데이터는 집계되지 않습니다.

## 자동으로 연결되는 범위

- **1~12월 전체 날짜**의 달력 실제 지출, 거래별 천 원 올림 테트리스, 월간 합계와 각 월 계산기의 분류별 숫자·색상이 연결됩니다. 달력은 카드 전용이 아니며 본인 변동지출의 현금 결제도 포함합니다.
- 급여·용돈·상여·기타 수입, 기존 고정비 항목, 자산형성·공동계좌 납입을 해당 월에 연결합니다. 새로운 정기비는 월간의 `기타 고정비 · RAW 추가/변경`에 표시합니다.
- 고정비 실제 확정액과 실적+미결제 예정액은 분리합니다. 예정 거래가 실제 들어오면 같은 항목의 예정액과 중복 합산하지 않습니다.
- 이체·카드대금 납부·공동통장 전체 사용·대납은 본인 변동 소비와 구분합니다. 특별한 예비비 재원이나 공동 부담은 거래명만으로 확정할 수 없으므로 J/K/L에서 확인·수정해야 합니다.
- 9~12월 추가 실지출 표에 이미 등록된 RAW 거래는 한 번만 반영합니다. **새 RAW 거래를 추가 실지출 표에 또 복사할 필요는 없습니다.** RAW에 없는 별도 수기 조정만 기존 추가 실지출 표로 등록합니다.
- 일시·자산·분류·소분류·내용·금액·유형·추가입력이 모두 같은 **새 중복 행은 집계에서 제외**합니다. 기존 중복 의심 행은 과거 합계를 바꾸지 않고 `기존 중복 확인`으로 표시합니다. 완전히 같지만 실제 별개 결제라면 원본 메모 등 구분 근거를 입력합니다.
- 금액 변경·음수 환급도 반영합니다. 잘못된 일시 등과 2026년 밖 거래는 안내하며 2026년 집계에 섞지 않습니다.

기존 1~10월에는 수기·특수 정산 이력이 섞여 있으므로 RAW 전체를 다시 분류해 과거 합계를 덮어쓰지 않았습니다. 숨김 `_RAW자동연동`에 기존 기록과 당시 RAW 집계를 보관하고 **기존 월간 값 + RAW 집계 증감**으로 연결했습니다. 특수 부담·목적재원 조정은 유지합니다. 11~12월 실제 미입력 수입·고정비·지출은 0으로 두고 예정액은 따로 남겼습니다. 숨김 기준값을 지우거나 일회성 변환 스크립트를 다시 실행하지 않습니다.

## 잔액·예비비와 계산기 유의점

**이번 자동화는 RAW → 월간·계산기입니다. 새 WRAP 입출금이나 예비비 목적 계정 배분까지 원장에 자동 등록하지 않습니다.** 잔액·예비비는 기존 원장 기준이며 N열과 사용안내에 표시합니다. 목적재원 여부는 확인 후 원장·예비비에 별도로 등록해야 합니다. 기존 잔액·예비비의 XML·수식·입력·저장값은 첨부본 그대로 보존했습니다.

계산기의 기존 색상 위치와 분류별 기준값은 보존하고 RAW 증감을 조건부 서식으로 추가·차감합니다. 월별 **8,000칸(1칸 1,000원)**까지 준비했으며 이를 넘으면 표시 범위 초과를 안내합니다. 초과해도 숫자 합계는 유지합니다. 예전 Calculate 버튼은 `RAW 자동`으로 표시하고 과거 색상 집계 매크로 연결을 해제했습니다. VBA 바이너리는 첨부본 그대로이며 실행하거나 새 코드를 넣지 않았습니다. 예전 `colorfunction` 매크로를 수동 실행하면 자동 수식을 덮어쓸 수 있으므로 사용하지 않습니다.

최종 XLSM은 ZIP/XML 단위로 수정했습니다. LibreOffice에서 **매크로를 제거한 임시 사본**을 재계산하고 결과 캐시만 최종 패키지에 반영했습니다. 무관한 예비비 조회 수식 582개의 빈 값이 LibreOffice에서 0으로 직렬화된 부분은, 수식과 모든 금융값이 그대로인지 확인한 후 원래 빈 캐시를 유지했습니다. RAW 가독성과 새 계산기 조건부 색상은 임시 PDF로 시각 확인했습니다.

**Microsoft Excel/SharePoint 실제 UI 실행 검증은 하지 못했습니다.** 표 확장은 수식·표 정의를 확장한 시험본으로 확인했으며 보호 상태에서 자동 확장된다고 주장하지 않습니다. 구조 검사는 대상 요소 순서·관계·메타데이터 검사이며 ECMA-376 전체 인증은 아닙니다. 실제 은행 잔액이나 거래 용도의 정확성을 새로 보증하는 작업도 아닙니다.
