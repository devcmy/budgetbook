# 9~12월 사용금액 요약표 정리

2026-10-19(Asia/Seoul). 사용자 요청에 따라 9월·10월·11월·12월 월간 탭에 같은 6개 항목을 표시합니다. 10월의 기존 14줄 상세·검증 설명표는 대체하고 다른 월에는 동일한 요약표를 추가했습니다. 거래·분류·달력·계산기·예비비·잔액은 변경하지 않았습니다.

## 표시와 계산 기준

모든 월에서 `72행`은 제목, `73~78행`은 아래 순서입니다. 숫자는 `E열`, 짧은 설명은 `J열`에 표시합니다. 인쇄 범위도 78행까지 맞췄습니다.

| 항목 | 계산 |
|---|---|
| 월급 예정 | 기존 급여 기준의 참고 예상액. 실제 수입에 새로 가산하지 않음 |
| 고정비 | 고정비 표의 확정·결제·RAW 확인·기존 입력 합계. 미결제 예정 제외 |
| 가계부 달력합계 | 기존 달력 실제 합계 `I33` |
| 테트리스 달력합계 | 기존 달력의 거래별 천원 올림 합계. 실제 사용 합계에는 다시 더하지 않음 |
| 실 사용금액 합계 | 고정비 + 가계부 달력합계 + 당월 대리·미리결제 원금 |
| 최종 사용금액 | 실 사용금액 합계 + 추가 실지출 `H39` |

고정비는 ‘실 사용금액’이라는 명칭에 맞춰 **실제 확정액 기준**을 적용했습니다. 10월 미결제 예정 762,073원은 고정비 설명에 별도로 표시하되 두 사용금액 합계에는 넣지 않습니다. 미래 11~12월의 원래 고정비 예상 입력은 유지하지만 신규 요약표의 실제 고정비에는 포함하지 않습니다. 9월 관리비·교통비의 ‘기존 입력’도 기존 실적대로 유지하며 원장으로 새로 확정한 것으로 표현하지 않습니다.

대리·미리결제는 해당 월 RAW 중 `지출`이며 분류가 `대납 / 대리결제 / 미리결제 / 선결제`인 원금 `G열`을 집계합니다. 본인 부담 `K열`은 대납에서 0이므로 대신 원금을 사용합니다. 이는 **당월 결제 총액**이며 ‘미회수 잔액’이나 ‘순수 본인 소비’와는 다릅니다. 회수 여부를 바꾸더라도 원래 그달 결제 사실을 없애지 않습니다. 새로운 거래를 메모 문구만으로 대납으로 임의 재분류하지 않았습니다.

카카오페이 충전 같은 내부이체·카드대금 납부·회수 입금은 이 원금 합계에 넣지 않습니다. 플라잉 더치·두끼는 달력에 이미 포함됐으므로 추가 실지출의 ‘이미 집계’를 차감해 추가 합산 0원을 유지합니다. 보증보험료는 달력 밖 추가 실지출 110,075원으로 최종 합계에 한 번만 더합니다.

위 표의 구성액 2줄은 검증 문서에서만 풀어 쓴 것입니다. 엑셀 요약표는 요청한 6줄이며, 구성액은 실 사용금액·최종 사용금액의 짧은 설명에 표시합니다.

기존 `H44/I44`의 ‘지출·적립 합계’와 이번 새 요약의 사용금액은 기준이 다릅니다. 기존 표는 공동계좌 납입·저축·적립·환급 등을 포함하는 수입 배분이고, 새 요약은 사용자가 지정한 결제 구성액 합계입니다. 서로 같은 값으로 강제하지 않았고 WRAP 잔액도 재차 차감하지 않았습니다. 현재 WRAP 생활비 4,409,691원·총액 6,559,691원, 예비비 목적잔액 2,150,000원·생신 사용 239,000원은 그대로입니다.

## 정리한 상세와 보존

모임계좌 전체 사용·가족행사 실비·형제자매 반환·가족계좌 출금·예비비 사용·대납 미회수의 장문 설명·RAW 검증·월급만 기준 배분을 기존 하단 설명표에서 제거했습니다. 관련 실제 거래·기존 수입 배분·예비비 표는 보존하며 검증 탭은 다시 만들지 않았습니다. 옛 표와 근거는 [변경 전 보관본](history/2026-10-19/05/SNAPSHOT.md) 및 Git 이력에 남아 있습니다.

## 검증

- 원본 XLSM ZIP 파트 중 변경은 9~12월 월간 시트 4개·해당 인쇄 범위·추가 요약 스타일뿐입니다. RAW·잔액·예비비·다른 월·모든 계산기·VBA·도형·관계 파일은 바이트 동일합니다.
