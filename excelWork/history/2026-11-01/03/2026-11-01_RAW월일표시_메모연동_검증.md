# RAW 월·일 표시와 월별 메모 연동 확인

작업일 2026-11-01(Asia/Seoul). 데이터 기준일 2026-10-31. 운영 파일은 `테트리스_가계부_2026_고도화.xlsm`입니다.

## RAW 날짜 표시

RAW **A열 ‘일시’**를 `10월 31일`처럼 월·일로 표시합니다. 표시 형식은 `m"월" d"일"`이며 준비된 4,000개 입력 칸에 적용했습니다. A열 너비는 13으로 조정했습니다.

**실제 2026년 날짜와 시·분·초/소수초는 그대로입니다.** 텍스트로 바꾸거나 시간을 잘라 저장하지 않았습니다. 수식 입력줄에서 원래 값을 확인할 수 있으며 중복 판정·월별 집계의 시간 기준은 유지합니다. B열 ‘월’은 기존 `2026-10` 표시와 월별 필터를 유지합니다. 입력할 때는 이전처럼 날짜 값을 붙여넣고, 표시 서식을 덮어쓰지 않도록 값 붙여넣기를 사용합니다.

최종 XLSM에서 변경한 ZIP 파트는 RAW 시트 XML과 스타일 XML 두 개뿐입니다. 기존 스타일을 직접 바꾸지 않고 날짜 표시용 스타일을 복제해 글꼴·색·입력 잠금 상태를 보존했습니다. 모든 실제 날짜 값·수식·캐시·메모와 다른 시트/VBA/관계/그림 파트는 그대로입니다.

## 월별 메모가 보이는 위치

| 위치 | 연결 내용 |
|---|---|
| RAW I열 | 메모 입력·수정·삭제의 원본 |
| 각 월별 탭 V34:AA40 | 해당 월 RAW 메모 목록. W40에서 5건 단위 페이지 선택 |
| 각 월별 탭 V4:V24, V26 | 해당 고정비 거래의 RAW 메모 |
| RAW와 연결된 추가 실지출 표 I열 | 해당 RAW 거래의 메모 |
| 각 월 계산기 A157:U162 | 월별 탭과 같은 페이지의 메모 |

월별 탭에서는 오른쪽으로 스크롤하면 V열의 메모 영역이 나옵니다. **메모 수정은 RAW I열에서 합니다.** 다른 탭의 표시 수식을 덮어쓰지 않습니다. 메모 삭제는 거래 삭제가 아니므로 해당 거래의 금액·분류·달력·잔액은 유지합니다. 삭제한 메모는 목록에서 빠지고 뒤의 메모가 당겨져 보입니다.

11~12월은 현재 실제 거래가 없어 메모도 빈칸인 것이 정상입니다. 연결 수식이 없는 것이 아닙니다. 일반 안내문, RAW와 무관한 수기 이월/정산의 독립 메모, 숨김 과거 이력은 RAW 메모 삭제 대상으로 취급하지 않습니다. RAW에 남아 있는 과거 설명 문구는 저장된 메모 텍스트이지 새로 생성하는 분석 문장이 아닙니다.

## 확인 방법

1. 현재 실제 RAW로 1~12월의 메모 건수·선택 페이지·각 고정비 메모·추가 실지출 메모를 독립 대조합니다.
2. 사본에서 기존 RAW 메모를 모두 지워 연결된 보기들이 비워지고 금융값은 그대로인지 확인합니다.
3. 다른 사본의 빈 행에 **각 월별 변동비 1건·고정비 1건(총 24건)**과 서로 다른 시험 메모를 입력합니다. 1~12월 모두 메모 목록·고정비 메모·계산기에 정확한 내용이 나오는지 재계산합니다.
4. 같은 거래를 유지한 채 시험 메모만 지운 사본을 재계산합니다. 모든 월의 해당 메모가 비워지되 거래 금액·분류·달력·계산기 숫자는 유지되는지 대조합니다.

시험 거래와 시험 메모는 `/tmp` 사본에만 있습니다. **운영 파일에 시험 거래를 추가하거나 사용자의 실제 메모를 지우지 않습니다.** 날짜 서식 변경 전후에 값과 수식이 동일함을 XML 단위로 검사하고, 월별 메모 변경·삭제는 매크로 없는 LibreOffice 사본의 재계산으로 확인합니다. 최종 파일을 LibreOffice나 openpyxl로 통째로 다시 저장하지 않습니다.

현재 거래 수·금융값은 그대로입니다: 전체 RAW 2,588건, 10월 267건, 달력 실제 2,605,157원, 테트리스 2,649,000원, WRAP 원장 총액 8,434,741원입니다.

결과: 단위/기존 회귀 132개 통과. 현재 12개월 메모 목록과 고정비, RAW 연결 추가 실지출 메모 13칸을 대조했습니다. 기존 메모 전량 삭제 시험은 158,682개 숫자·날짜/계산값 차이 0 및 연결 메모 958칸 비움을 확인했습니다. 각 월별 시험 메모 입력·삭제를 비교한 158,946개 값도 차이 0이며 거래 금액이 유지됐습니다. 패키지 구조 검사 오류는 0입니다.

줄바꿈 검증의 한계: 기존 저장된 메모 계산 캐시 일부는 원문 I열의 줄바꿈이 빠져 있습니다. 임시 재계산 도구가 단순한 `=A1`에서도 입력 셀의 줄바꿈을 제거하는 현상을 별도 소형 사본으로 재현했습니다. 따라서 캐시의 글자 내용·연결을 대조하면서 줄바꿈 차이는 별도로 기록했으며, 도구에 맞추려고 사용자의 원문을 바꾸지 않았습니다. **이번 파일의 모든 RAW 메모 원문과 기존 메모 캐시는 변경 전과 동일**합니다. 실제 Microsoft Excel의 줄바꿈 표시까지 확인했다는 뜻은 아닙니다.

Microsoft Excel/SharePoint 실제 UI 실행은 하지 못했습니다. 구조 검사와 재계산 검증을 실제 Excel의 복구 오류 미발생 보증으로 해석하지 않습니다.
