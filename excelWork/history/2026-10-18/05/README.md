RAW 양쪽 비고와 잔액 원장·조회표에 구매 목적을 표시합니다. 금액·분류·수식은 바꾸지 않았고 차액 1,300원의 실제 재원은 미확정으로 남깁니다. 현재 파일 해시는 [연결 검증](kakaopay_purchase_link_validation.json)과 `audit.json` 최상위, 연결 표시 전 파일은 [history/2026-10-18/04](history/2026-10-18/04/SNAPSHOT.md)입니다. 위 RAW 검증 해시는 거래 추가 직후 이력입니다.

신규 본인 지출은 17건 **177,160원**(테트리스 180,000원), 모임통장 사용은 2건 36,800원입니다. WRAP→카카오페이 충전 15,700원은 WRAP 생활비에서 한 번만 차감하고, 카카오페이 구매 17,000원만 소비에 반영합니다. 현재 WRAP 생활비 **4,519,766원**, 임시보관 **0원**, 합계 **6,669,766원**이며 목적자금 **2,150,000원**과 선택월 예비비 사용 **239,000원**은 그대로입니다.

예비비 현황의 명칭은 **선택월 예비비 사용액**, 10월 생신 본인 사용은 **239,000원**입니다. 명절비 200,000원과 임시보관 39,000원을 기존 송금에 연결해 정산대기 0원을 유지합니다. 가족통장에서 회수한 원금 61,000원은 먼저 WRAP 임시보관으로 복귀시켰습니다. 가족통장에 남은 본인 이자는 제공 거래 누적 기준 25원입니다. 생신 정정 전 버전은 [history/2026-10-15/04](history/2026-10-15/04/README.md), 당시 검증은 [family_event_validation.json](family_event_validation.json)입니다.

최신 UI 변경(2026-10-18): 잔액 탭의 **조회월(B3)** 하나로 상단 잔액·기존 상세 내역·새 하단 WRAP 원장을 함께 조회합니다. 첫 표의 이체 보냄·받음은 원래도 선택월만 집계하며, WRAP 내부 계정 이동도 포함합니다. 내역 월(B35)은 자동 연동 표시로 바꿨고 별도 월 입력은 없앴습니다. 하단에는 선택월 원장만 22건씩 최신순으로 표시하며, 전체 입력 원장 64~500행은 같은 탭에서 기본 접어 둡니다. 편집할 때만 왼쪽 **+**를 펼칩니다. 원본 행번호·실제 거래·기존 재무 수치는 유지합니다. 변경 전 버전은 [history/2026-10-18/01](history/2026-10-18/01/README.md), 최신 검증은 [balance_selected_month_validation.json](balance_selected_month_validation.json)입니다.

Excel 복구 오류 후속 수정: 잔액 탭의 행 접기 설정 XML이 스키마 순서에 맞지 않았던 문제를 고쳤습니다. `sheetPr` 안에서 `outlinePr`를 `pageSetUpPr` 앞으로 이동했으며, 이 수정은 이번 RAW 갱신에서도 유지합니다. 오류 재현본은 [history/2026-10-18/02](history/2026-10-18/02/README.md), 당시 수정 검증·해시는 [excel_xml_repair_validation.json](excel_xml_repair_validation.json), 현재 구조 검증·해시는 최신 RAW 검증과 `audit.json`을 따릅니다. 이전 계산 검증이 Excel의 XML 로드 호환성까지 보증하지 못했던 한계를 보완했습니다. SharePoint에서 복구해 저장한 파일 대신 최신 기준본으로 교체해 사용합니다.

월별 비교표와 고정된 기준월 검증은 화면의 조회월과 독립적으로 유지합니다. 거래가 없는 미래 월은 원장 **0건**, 잔액은 기존 기록의 이월액이며 예상 수입·지출을 넣은 예측치가 아닙니다. 현재 거래 기준일은 첨부된 원장에 따라 10/18로 갱신했습니다.

예비비는 **현황 / 계획 / 이체 내역** 한 탭으로 정리했습니다. 조회월에 맞춰 원장잔액·정산대기·사용가능액과 사용·이체를 조회하며 1~12월 월간 계획·실제 사용과 연결됩니다. 원장잔액은 같은 월의 잔액 탭과 일치하고, 사용가능액은 미정산 사용분을 뺀 금액입니다. 두 탭의 조회월은 독립적이므로 다르면 안내합니다. 카드 사용과 다음 달 이체를 중복 소비로 잡지 않습니다. 별도 정산 탭은 없고 고정 등록 자료는 같은 탭 아래 접어 둡니다. 개편 전 버전은 [history/2026-10-15/03](history/2026-10-15/03/README.md)에 보관했습니다.
