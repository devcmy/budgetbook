## 3. 새 ‘입력·연결’ 탭 사용법

이 탭은 별도 지출 원장이 아니라 **원본 거래를 확인하고 실제 입력 위치로 이동하는 화면**입니다. 검색칸의 금액·메모를 바꿔도 지출은 등록되지 않습니다.

1. `B3` 처리유형을 고르고 `G3` 조회월을 선택합니다. 금액 `B4`, 거래일 `G4`, 자산 `B5`, 내용/메모 검색 `G5`로 후보를 좁힙니다.
2. 아래 후보의 **거래ID**를 `B7`에 입력합니다. 행을 클릭하면 자동 선택되는 방식은 아닙니다. ID는 RAW의 AP열 값이며 정렬 후 화면 행번호와 다릅니다.
3. 원금·본인부담·분류·RAW 메모·기존 원장 연결을 확인합니다. 기존 거래는 같은 ID를 `G8` 확인용 ID에 다시 입력합니다. 조회월·금액·날짜·자산이 맞아야 수정 위치 링크가 활성화됩니다.
4. 아래 링크로 원본 칸에 이동해 수정합니다. **원본 변경이 저장된 연결입니다.** 검색창을 다음 거래로 바꿔도 이미 저장한 RAW 분류/연결코드는 지워지지 않습니다.

신규 실제 거래는 기존 후보와 중복되지 않는지 확인하고 처리유형을 ‘신규 RAW 등록’, 확인용 ID를 **0**으로 입력합니다. RAW의 새 빈 행에 입력하며 기존 거래 행을 재사용하지 않습니다. 은행 송금 없는 WRAP 내부 계정이동도 확인용 ID 0을 사용하지만, 새 RAW는 만들지 않습니다.

| 처리할 내용 | 실제 저장 위치와 주의사항 |
|---|---|
| 새 실제 거래 | RAW A 일시, C~I 거래. A는 실제 날짜·시간 값이며 화면에는 월·일로 표시합니다. |

| 고정비 항목 연결 | RAW J를 고정비로 선택한 뒤 새 AQ ‘고정비 연결코드’를 선택합니다. `G7`에서 선택월의 항목명과 코드를 확인합니다. |
| 미결제 예정액 수정 | **11·12월 AB4:AB24, AB26**의 노란 ‘예정 입력’. 실제 RAW 청구가 있으면 실제 금액이 우선하며 예정은 다시 더하지 않습니다. 10월 등 마감월 예정은 새로 쓰지 않습니다. |
| 메모 수정·삭제 | RAW I만 수정합니다. 연결된 월별/계산기/원장/예비비 메모에 반영되며 분류·금액은 바뀌지 않습니다. |
| WRAP 실제 입출금 연결 | 잔액 탭의 접힌 입력 원장을 펼쳐 실제 계정과 W/X 거래ID를 지정합니다. WRAP 관리범위의 거래만 한 번 연결합니다. 카드소비를 현금출금으로 재차 등록하지 않습니다. |
| WRAP 내부 계정이동 | 은행 거래 없는 내부 분류이동은 RAW W/X를 비워 두고 원장의 보낸/받은 계정·금액을 입력합니다. 총현금은 보존합니다. |
| 예비비 부담 연결 | 예비비의 접힌 사용등록에서 실제 목적항목·본인부담과 F 거래ID를 확인합니다. 카드대금/정산은 원장과 별도로 확인하며 목적 계정을 추정하지 않습니다. |
| 공동비용·대납 정산 | 원거래 본인 부담·미회수액·실제 회수 거래를 먼저 확인합니다. 화면은 확인 절차와 원본 위치를 안내하며 분담/정산을 자동 생성하지 않습니다. |

AQ 코드는 **4~24 및 26**입니다. 빈칸이면 기존 자동 매칭을 사용합니다. AQ만 입력하고 J를 고정비로 지정하지 않거나 일반 이체에 고정비를 강제하면 입력확인 N에 경고하며 수동 연결을 적용하지 않습니다. **경고가 거래 전체를 보류하는 것은 아닙니다.** 기존 자동 분류·집계는 계속 작동하므로 N열 경고를 확인해야 합니다.

실제 고정비와 상태·달력·합계·연결 메모 수식을 직접 덮어쓰지 않도록 10~12월에 입력 안내/유효성 검사를 추가했습니다. 추가 실지출도 RAW에 한 번만 등록합니다. 메모는 검색에만 사용할 수 있으며 고정비·중복·부담을 결정하는 조건으로 쓰지 않습니다.

### 구현 범위와 제한

- VBA는 수정하거나 실행하지 않았습니다. 수기 입력 때 자동 질문 팝업이 뜨거나 후보를 자동 확정하는 기능은 아닙니다. 안내 화면에서 사용자가 확인하는 절차입니다.
- 유효성 검사는 일반 타이핑에 대한 안내·차단이며 보안 잠금이 아닙니다. **붙여넣기로 우회될 수 있고 RAW 직접 입력은 즉시 자동 연동**됩니다. 승인 전 집계를 막는 별도 대기 원장은 없습니다.
- 1~9월/계산기의 사용자 숨김은 유지합니다. 신규 탭 한 개만 추가해 전체 **47개(표시 11·숨김 36)**입니다. 검증 탭은 없습니다.
- RAW 표는 `A1:AQ4001`로 확장했습니다. AP는 고정 거래ID, AQ는 선택적 고정비 연결코드이며 원래 오른쪽 안내/분류 목록은 `AR:AW`로 옮겼습니다. 정렬 때 AQ도 거래와 함께 이동합니다.
- 기존 2,597건과 모든 현재 금액은 유지합니다. 새 실제 거래를 임의로 추가하지 않았습니다. 전체 삭제 초기화·행삭제·기존 행에 다른 거래 덮어쓰기는 여전히 지원하지 않습니다.
- 새 RAW는 빈 행에, 메모는 I에, 예정은 AB에 입력합니다. 기존 ID·계산식을 수정하지 않습니다. 4,000건 준비영역 중 1,403건이 남아 있습니다.
