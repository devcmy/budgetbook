# 임시보관 61,000원 → 생활비

10/18 UI 변경: 이 문서의 잔액·사용액은 유지합니다. 현재 원장 조회 방식과 최신 파일 검증 해시는 [잔액·원장 조회월 연동](2026-10-18_잔액원장조회월_검증.md)을 따릅니다.

사용자 요청: 가족통장에서 회수해 임시보관에 둔 61,000원을 생활비로 옮깁니다. 변경 전 `e8d5f26` 기준본·문서는 [history/2026-10-15/05](history/2026-10-15/05/README.md)에 보관합니다.

## 반영 방식

잔액 원장 **247행**에 `임시보관 → 생활비 / 61,000원`의 WRAP 내부 계정 이동을 추가합니다. 양쪽 은행 표시는 같은 WRAP이며, 일시는 사용자 시간대 Asia/Seoul의 분류 기록 시각입니다. 실제 은행 송금 시각으로 꾸미지 않습니다.

원장 246행의 가족통장 → WRAP 원금 회수 61,000원은 그대로 보존합니다. 247행은 그 다음 자금 배분 단계입니다. 실제 거래가 아니므로 RAW에 새 은행 거래를 만들거나 회수 거래의 RAW 연결을 중복하지 않습니다. 내부 이동은 양쪽 계정의 이체 보내기·받기에 반영되고 총현금은 상쇄됩니다.

잔액 탭 상단과 월별 계정 잔액은 기존 수식으로 연결되며 UI·조회월 선택 기능을 바꾸지 않습니다. 새로운 수입·지출·예비비 적립이 아닙니다. 과거 3~9월 잔액, RAW 2,465건과 10월 144건, 모든 월간 생활비·수입·월급 부담·테트리스·생신 정산은 유지합니다.

## 검증

`scripts/move_temporary_to_living.py`가 OOXML 원본 패키지를 유지해 수정하고 9월(이동 전), 10월(이동 월), 11월(이월)을 재계산합니다. 잔액·예비비 동일월 대조와 WRAP 합계, 새 원장행의 유효성, 과거 월 잔액 보존을 확인합니다. 잔액 외 재무 값과 RAW·월간·계산기·매크로·컨트롤·스타일도 이전 버전과 비교합니다. 숨김 원장 조회 보조 날짜 셀은 새 행의 일시를 반영합니다.

최신 결과·해시는 [temporary_to_living_validation.json](temporary_to_living_validation.json)에 기록합니다. 이전 생신 정산의 12개월·4개 시나리오는 당시 파일의 검증 이력이며, 이번에 모두 재실행한 것은 아닙니다. 임시 매크로 없는 XLSX에서 LibreOffice로 재계산한 뒤 캐시만 XLSM에 옮기며 Excel 데스크톱 매크로·실제 UI 클릭은 실행하지 않습니다.

검증 결과: 9·10·11월 선택·동일월 잔액 대조 통과, 수식 오류 0건입니다. 잔액 외 재무 값·RAW·월간·계산기·생신 사용과 정산 값은 모두 유지되며, 검증 시트의 논리 검사는 전부 TRUE입니다. WRAP 합계와 실제 입출금은 유지하고 10월 원장만 내부 분류 이동 1건이 늘어 총 15행(실거래 RAW 연결 14행 + 내부 이동 1행)이 됩니다.
