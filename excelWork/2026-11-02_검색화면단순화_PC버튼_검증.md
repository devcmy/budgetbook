# PC Excel 거래 검색 화면 단순화

현재 기준본: `테트리스_가계부_2026_고도화.xlsm`. 변경 전 커밋 `96d097e`, 사본 `history/2026-11-02/04`, 검증 `simple_search_20261102_validation.json`입니다.

## 사용법

1. **입력·연결** 탭에서 검색어를 입력합니다. 거래내용·메모·결제수단/계좌·금액을 찾습니다.
2. 월은 기본 **전체**입니다. 필요할 때만 특정 월로 바꿉니다.
3. 실제 **검색 버튼**을 누릅니다. 검색어를 비우고 누르면 해당 월의 모든 거래가 표시됩니다.
4. 결과의 **원본 수정 / 메모 수정**을 눌러 RAW에서 고칩니다. 검색 결과에 직접 금액을 입력하지 않습니다.

처리유형 8개·후보 아래 별도 상세표·거래ID 수기 입력·같은 ID 재확인을 없앴습니다. 최초 화면에는 최근 10건을 미리 보여주며 검색을 누르면 전체 2,597건에서 조건에 맞는 거래를 찾습니다. 결과를 10건으로 제한하지 않습니다.

새 거래·11/12월 예정액·WRAP 원장·예비비 사용등록은 위쪽의 짧은 이동 링크로 남겼습니다. 실제 거래는 RAW, 메모는 RAW I, 예정은 월별 AB라는 저장 원칙은 같습니다. 목적 계정·공동분담을 추정하거나 자동 생성하지 않습니다.

## 버튼과 보안

이 버튼은 PC Excel의 **VBA 매크로 `BB_Search`**를 호출합니다. 파일 출처와 코드를 확인한 경우에만 매크로 실행을 허용합니다. 조직 보안정책을 바꾸거나 Excel 전체 보안을 낮추지 않습니다. 실행이 차단되면 기존 RAW 표의 필터를 사용할 수 있습니다.

버튼은 RAW를 읽고 검색 결과만 작성합니다. 거래 금액·분류·메모·예비비/잔액 원장을 수정하거나 송금하지 않으며 파일/네트워크/외부 프로그램을 실행하지 않습니다. 결과 이동 시 거래가 가려지지 않도록 RAW 표시 필터만 해제합니다. 시작 시 자동 실행되는 코드는 없습니다.

기존 VBA 13개 모듈의 **소스는 그대로 보존**하고 검색 모듈 한 개를 추가했습니다. 새 소스가 사용되도록 VBA의 재생성 가능한 성능/컴파일 캐시를 제거한 소스 전용 프로젝트로 재구성했습니다. VBA 바이너리 전체가 이전과 동일하다는 뜻은 아닙니다.

## 검증과 한계

- RAW A:AQ 172,000개 값과 기존 실제 금융 셀 6,343개를 대조합니다. 기존 RAW 2,597건·모든 실제액·예정액·숨김 상태는 유지하며 새 거래는 추가하지 않습니다.
- 독립적인 OLE/VBA 파서로 새 프로젝트와 버튼 연결을 읽고, 기존 13개 소스와 추가 모듈을 대조합니다. 자동 테스트 181개를 통과했습니다.
- ‘전체’에서 글램핑 거래 ID2515 검색, 11월에서는 제외, 303 검색 시 네이버플러스 조회를 확인합니다. 검색어는 분류 기준이 아닙니다.
- 임시 매크로 없는 사본에서 RAW를 정렬하고 캠핑 메모를 지운 뒤 결과의 거래·금액·빈 메모·이동 링크를 재계산합니다. 결과는 내부 고정 ID를 따라가므로 정렬에 의존하지 않습니다.
- 실제 Microsoft Excel의 VBA 컴파일/버튼 클릭과 사용자 PC 보안 설정은 이 환경에서 실행 검증하지 못했습니다. 구조·소스·검색 조건·연결 수식 검증과 PC Excel 실행 검증을 구분합니다. 별도 사본 PDF는 화면 배치 참고용입니다.

검색 조건이나 원본 내용이 바뀌면 검색 버튼을 다시 누릅니다. 기존 결과에 표시된 금액·메모·이동 위치는 원본을 따라가지만, 검색 조건에 맞는 **결과 구성**은 마지막 검색 시점의 목록입니다. RAW를 삭제·재사용하거나 거래ID를 고치지 않는 기존 제한도 유지합니다.
