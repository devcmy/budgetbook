# Excel 작업 폴더

이 폴더에 가계부 엑셀의 기준본, 참고용 원본, 분석 문서와 이후 작업 결과를 모읍니다. 엑셀의 양식·계산·회계 기준을 다듬고 검증한 뒤 앱 개발에 이관합니다.

| 파일 | 역할 |

| [여행_One.xlsx](여행_One.xlsx) | 여행 공동비용·분담·송금 정산 원본 |

| [audit.json](audit.json) | 현재 기준본의 수치 대조 결과 |

## 이후 작업 결과 보관

- `main` 브랜치에서 작업하고 커밋·푸시합니다. 별도 작업 브랜치가 필요한 경우에는 사용자의 별도 지시를 따릅니다.
- 새 수정 요청은 이 폴더의 최신 고도화 파일을 기준으로 이어갑니다. 참고용 원본 세 파일은 보존합니다.
- 완료한 수정본의 이름은 `테트리스_가계부_2026_고도화.xlsm`으로 유지합니다.
- 다음 수정부터는 기준본을 갱신하기 전에 이전 버전과 그 분석·검증 자료를 `history/YYYY-MM-DD/01/`에 보관합니다. 같은 날 추가 작업은 `02/`, `03/` 순서로 쌓습니다. 폴더 날짜는 사용자 시간대인 Asia/Seoul을 기준으로 합니다.
- 현재 작업의 최신 결과는 이 폴더에서 찾고, 이전 결과는 날짜별 이력과 Git 커밋에서 확인합니다.
- XLSM 내부 형식·VBA·수식·달력·테트리스 블록과 잔액 연결을 보존하고, 확인한 범위와 미확인 항목을 작업 문서에 남깁니다.

현재 보관한 네 엑셀은 사용자 첨부 파일의 바이트를 그대로 유지했습니다. 앱의 초기 데이터는 별도로 관리하며, 엑셀 작업이 확정된 뒤 이관합니다.
