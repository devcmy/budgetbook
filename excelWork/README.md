최신 기준일은 **2026-10-15**입니다. 전체 RAW 2,465건, 10월 144건이며 본인 생활비 1,299,740원 / 테트리스 1,321,000원입니다. 미회수 철도 대납금 2건 103,600원은 본인 소비에서 제외합니다. RAW 반영 전 버전은 [history/2026-10-15/01](history/2026-10-15/01/README.md), 조회월 선택 기능 추가 전 버전은 [history/2026-10-15/02](history/2026-10-15/02/README.md)에 보관했습니다.

예비비 현황의 명칭은 **선택월 예비비 사용액**, 10월 생신 본인 사용은 **239,000원**입니다. 명절비 200,000원과 임시보관 39,000원을 기존 송금에 연결해 정산대기 0원을 유지합니다. 가족통장에서 회수한 원금 61,000원은 먼저 WRAP 임시보관으로 복귀시켰습니다. 가족통장에 남은 본인 이자는 제공 거래 누적 기준 25원입니다. 생신 정정 전 버전은 [history/2026-10-15/04](history/2026-10-15/04/README.md), 당시 검증은 [family_event_validation.json](family_event_validation.json)입니다.

최신 변경: 사용자 요청에 따라 회수금 **61,000원을 임시보관에서 생활비로 이동**했습니다. 생활비 **4,535,466원**, 임시보관 **0원**, WRAP 합계 **6,685,466원**입니다. 은행 간 실제 송금이나 새 수입·지출이 아닌 WRAP 내부 분류 이동이며, 생신 사용 239,000원은 그대로입니다. 이동 전 버전은 [history/2026-10-15/05](history/2026-10-15/05/README.md), 최신 검증은 [temporary_to_living_validation.json](temporary_to_living_validation.json)을 확인하세요.

잔액 탭의 **조회월(B3)**에서 3~12월을 선택하면 위쪽의 전월말·입출금·계정별 잔액·합계가 바뀝니다. **내역 월(B35)**은 아래 거래내역의 별도 선택입니다. 월별 비교표와 고정된 기준월 검증은 조회월 선택과 독립적으로 유지합니다. 거래가 없는 미래 월의 조회 잔액은 예상 수입·지출을 넣은 예측치가 아니라 기존 기록의 이월액입니다.

예비비는 **현황 / 계획 / 이체 내역** 한 탭으로 정리했습니다. 조회월에 맞춰 원장잔액·정산대기·사용가능액과 사용·이체를 조회하며 1~12월 월간 계획·실제 사용과 연결됩니다. 원장잔액은 같은 월의 잔액 탭과 일치하고, 사용가능액은 미정산 사용분을 뺀 금액입니다. 두 탭의 조회월은 독립적이므로 다르면 안내합니다. 카드 사용과 다음 달 이체를 중복 소비로 잡지 않습니다. 별도 정산 탭은 없고 고정 등록 자료는 같은 탭 아래 접어 둡니다. 개편 전 버전은 [history/2026-10-15/03](history/2026-10-15/03/README.md)에 보관했습니다.
