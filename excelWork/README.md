최신 기준일은 **2026-10-15**입니다. 전체 RAW 2,464건, 10월 143건이며 본인 생활비 1,299,740원 / 테트리스 1,321,000원입니다. 미회수 철도 대납금 2건 103,600원은 본인 소비에서 제외합니다. RAW 반영 전 버전은 [history/2026-10-15/01](history/2026-10-15/01/README.md), 조회월 선택 기능 추가 전 버전은 [history/2026-10-15/02](history/2026-10-15/02/README.md)에 보관했습니다.

잔액 탭의 **조회월(B3)**에서 3~12월을 선택하면 위쪽의 전월말·입출금·계정별 잔액·합계가 바뀝니다. **내역 월(B35)**은 아래 거래내역의 별도 선택입니다. 월별 비교표와 고정된 기준월 검증은 조회월 선택과 독립적으로 유지합니다. 거래가 없는 미래 월의 조회 잔액은 예상 수입·지출을 넣은 예측치가 아니라 기존 기록의 이월액입니다.

## 이후 작업 결과 보관

- `main` 브랜치에서 작업하고 커밋·푸시합니다. 별도 작업 브랜치가 필요한 경우에는 사용자의 별도 지시를 따릅니다.
- 새 수정 요청은 이 폴더의 최신 고도화 파일을 기준으로 이어갑니다. 참고용 원본 세 파일은 보존합니다.
- 완료한 수정본의 이름은 `테트리스_가계부_2026_고도화.xlsm`으로 유지합니다.
- 다음 수정부터는 기준본을 갱신하기 전에 이전 버전과 그 분석·검증 자료를 `history/YYYY-MM-DD/01/`에 보관합니다. 같은 날 추가 작업은 `02/`, `03/` 순서로 쌓습니다. 폴더 날짜는 사용자 시간대인 Asia/Seoul을 기준으로 합니다.
- 현재 작업의 최신 결과는 이 폴더에서 찾고, 이전 결과는 날짜별 이력과 Git 커밋에서 확인합니다.
- XLSM 내부 형식·VBA·수식·달력·테트리스 블록과 잔액 연결을 보존하고, 확인한 범위와 미확인 항목을 작업 문서에 남깁니다.

참고용 원본 세 엑셀과 첨부 RAW는 사용자 파일의 바이트를 그대로 유지합니다. 고도화 XLSM은 최신 RAW 반영 결과이며, 변경 전 버전도 보관합니다. 앱의 초기 데이터는 별도로 관리하며, 엑셀 작업이 확정된 뒤 이관합니다.
