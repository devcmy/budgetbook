현재 파일·해시는 [11/4 갱신 검증](2026-11-04_11월RAW추가_검증.md)와 `raw_update_20261104_validation.json`을 따릅니다. 1~10월 실제액·잔액은 유지하고 11월을 추가 반영했습니다. 위 날짜별 설명과 이전 검증 해시는 당시 이력입니다. 현재 파일은 **47개 시트(표시 11개·숨김 36개)**이며 검증 탭은 없습니다. 사용자 숨김 상태를 유지합니다.

RAW 표는 `A1:AQ4001`, 오른쪽 안내는 `AR:AW`입니다. 검색 결과는 원장이 아니며 실제 저장은 원본에서 합니다. 입력 유효성 검사는 붙여넣기로 우회할 수 있으므로 승인 전 집계를 막는 잠금은 아닙니다.
