# iPhone 17 Pro Max 실행 확인 · 미실행 항목

Linux 검증과 별개로 Mac/Xcode에서 다음을 확인해야 합니다. 데이터가 들어 있는 기존 앱을 삭제·초기화하지 말고, 별도 Bundle Identifier의 테스트 설치 또는 시뮬레이터에서 시작합니다.

1. `TetrisBudget` Run. 초기 예상 남는 돈 1,195,895원, 비고정비 286,580원, 고정비 1,248,055원, 비예비비 11,900원, 예비비 사용 0원 확인.
2. 예비비 잔액 2,150,000원, WRAP 8,480,881원, 생활비 6,330,881원 확인. 확정 결산 수입 4,180원·지출적립 336,280원 확인.
3. 일반 지출 10,000원을 WRAP 생활비에서 입력. 남는 돈·WRAP 각 10,000원 감소, 비고정비·비예비비 각 10,000원 증가, 추가 합산 0원 확인. 앱 종료·재실행 후 기록 유지 확인. 금액 수정·삭제 후 합계 복구 확인.
4. 여행 목적에 생활비에서 100,000원 실제적립. WRAP 총잔액 유지, 생활비 감소, 여행 자금·실제적립 증가 확인. 여행에서 40,000원 실제 사용. 해당 월 소비·목적자금·WRAP에 각 한 번 반영 확인.
5. 월세 예상 항목 391,000원을 실제 400,000원으로 대체. 예상 결산 지출은 9,000원만 증가하고 확정 지출은 400,000원 증가하는지 확인.
6. 카드 사용 50,000원 후 다음 달 카드대금 50,000원을 원래 지출에 연결. 소비는 사용 월 한 번, WRAP 출금은 납부 월 확인. 다른 달 정산의 귀속 월 미선택 저장 거절, 직접 지정 후 합계 확인.
7. 설정에서 이름 변경·재실행·기본값 복원, 글자 크게 설정, 투명도 감소, 5탭·키보드·시트 스크롤·안전영역·Glass 확인. 달력 월 시작 요일과 28/29/30/31일 확인.
8. JSON 백업 저장 → 거래 변경 → 백업 가져오기. 개수/잔액 확인 화면에서 취소·복원 각각 확인. 손상·다른 버전 JSON 거절, 현재 데이터 유지 확인. 기기 내 이전 저장본 확인 동작 확인.
9. 원본 RAW 보관함 전체 2,366건과 원문 검색·펼치기 확인. 과거 월은 미이관 표시이며 0원 완료 결산처럼 보이지 않는지 확인.
10. Test(⌘U): 네이티브 테스트 5개 실행. 실제 디스크 저장·오류·복원과 JavaScriptCore 실행 확인. 결과는 Linux의 33개 회계 및 18개 엑셀 모듈 테스트와 별도로 기록.

명령행 예시(설치된 시뮬레이터의 OS·이름에 맞게 선택):

```sh
xcodebuild -project ios/TetrisBudget.xcodeproj -scheme TetrisBudget -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max' test
```

11. 설정에서 합성 `tests/fixtures/import.xlsx`와 `import.xls`를 선택해 검토·취소·행 제외·고정비 예상 대체·저장을 확인. 같은 파일 재입력 중복 제외, 오류 파일 차단, 여러 시트 선택, 저장 실패 시 원본 유지 확인. 실제 사용자 엑셀 2,366건 중복 검토 및 Files 권한 확인.
