# 첫 iPhone 디자인

2026-10-06 제작. 기존 엑셀을 기준으로 한 디자인 제안이며, 최종 앱 이름·메뉴 구성을 사용자 확정으로 간주하지 않습니다.

## 방향

큰 숫자를 먼저 읽고, 그 숫자의 근거를 한 번 눌러 확인하는 구조입니다. 기본 바탕은 밝은 회색, 주요 결산은 네이비, 이동·선택·테트리스는 보라색입니다. 예상은 붉은색, 미확인은 파란색, 확정은 녹색과 **문자 상태**를 함께 사용합니다. 모양과 색만으로 상태를 전달하지 않습니다.

SwiftUI 시스템 글꼴과 SF Symbols를 사용합니다. 본문과 제목은 시스템의 의미별 글꼴, 금액은 숫자 폭을 맞춰 표시합니다. 하단 네 탭과 입력 버튼은 44pt 이상을 기준으로 구성했습니다. Safari 시안은 iOS 시스템 글꼴을 우선하며 Linux 스크린샷은 설치된 한국어 폰트를 사용하므로 실제 iPhone과 자간·아이콘·스크롤이 다릅니다.

| 화면 | 먼저 보이는 정보 | 이어지는 화면 |
|---|---|---|
| 이번달 | 예상 남는 돈, 총수입, 지출·적립 합계 | 결산 근거 → 고정지출 상태; 테트리스 비교; 최근 기록 |
| 기록 | 거래 내역, 검색, 달력 | 거래 상세; 지출·수입·이체 입력; 시안 수정·삭제 |
| 예비비 | 실제 남은 금액, 누적 적립·사용, 이번달 계획·실제 | 목적별 세부 항목, 예정일과 사용 내역 |

테트리스는 이번달 결산의 비교 기능입니다. 4×4 그래픽은 브랜드 장식이며 금액별 칸 수를 표현하지 않습니다. 하루 비교는 원본의 수기 표시값을 사용하며 새로운 반올림 규칙을 만들지 않습니다.

월간 수치는 Excel 저장값의 디자인용 보존입니다. 새 계산 모듈의 정확성 검증 결과로 사용하지 않습니다. 원본 행·RAW 금액을 유지하고, 계산을 구현할 때 기존 승인 사례와 대조합니다.

11·12월은 월간 결과 ‘미입력’을 사용하며 예비비 계획만 200,000원씩 표시합니다. 원본 11·12월 가족통장 200,000원 계획은 10월 이후 중단 지시와 충돌하므로 화면에 채택하지 않았습니다. 예비비·잔액 탭의 기준일은 월 선택과 독립적으로 10월 5일에 고정되어 표시됩니다.

아빠 생일은 예정일 10/9와 별개로 9월 200,000원 사용 완료·잔액 0원을 유지합니다. 이 항목은 ‘전체 항목’에서 조회합니다. WRAP의 내부 이동은 소비 입력과 구분하고, 두끼 RAW 2333행·잔액 표현, 공동 납입 RAW 2346행, 이자 RAW 2367행의 원본 상세를 연결했습니다.

## 입력 흐름과 범위

＋ → 지출/수입/이체 → 금액 → 내용·날짜·결제수단·분류·메모 → 시안 저장 → 기록 조회 → 수정/삭제입니다. 환급·정산의 음수 지출과 0원을 허용합니다. 원 단위 소수, 범위를 초과하는 정수, 음수 수입·이체, 빈 내용은 저장하지 않습니다. 기타=담배인 원본 분류를 새 이름으로 일괄 치환하지 않았습니다.

이체 화면의 분류 선택은 목적을 확인하는 초기 시안입니다. 출발/도착 계좌, 실제 소비인지 여부, 목적 적립과 원장 연결을 구현한 완성된 이체 모델이 아닙니다. 계좌·분류 선택은 대표 항목이며 전체 마스터 데이터·즐겨찾기·자동완성은 다음 개발에서 연결합니다. 카드사용·납부, 미정산/부분 정산, 거래 연결, RAW 이관도 계산 모듈과 함께 구현해야 합니다.

현재 저장은 프로세스 내 메모리입니다. 추가·수정·삭제는 시안 기록에만 동작하며, 원본 읽기 전용 스냅샷 및 결산 카드를 바꾸지 않습니다. 세션 종료 시 초기화된다는 안내를 입력 화면에 표시합니다. 실제 앱 완료로 주장하지 않습니다.

## 다음 구현의 기준

사용자 선택된 iOS 네이티브 방향에 맞춰 SwiftUI 화면과 계산 모델을 분리했습니다. 영구 저장은 다음 단계에서 로컬 저장 구조를 정하고, 원본 거래·재분류·정산·목적 계정 연결을 분리해 설계합니다. 거래 변경은 월간·예비비·잔액에 동일 근거로 반영하고 원본 거래가 여러 화면에서 중복 집계되지 않아야 합니다. 기존 분석의 20개 승인 사례를 계산 모듈에 연결한 뒤 데이터를 이관합니다.

출시 전 VoiceOver, 큰 글씨, 다크 모드, 실제 iPhone 키보드/안전영역, 데이터 백업·복원과 Xcode 빌드를 검증해야 합니다. 현재 기본안은 밝은 화면과 세로 방향입니다.
