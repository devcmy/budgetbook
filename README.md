# 테트리스 가계부 · iOS MVP 01

좋아하신 디자인 02를 실제 데이터를 다루는 SwiftUI 앱으로 연결했습니다. 개인용 iPhone 17 Pro Max 기준의 촘촘한 화면, 시스템 탭과 Liquid Glass, 탭·메뉴 이름 설정을 유지합니다. 기존 Excel의 용어와 회계 기준이 우선이며, 편한가계부는 거래 입력·관리 참고입니다.

## 최신 Excel 기준본과 분석

2026-10-14에 받은 [테트리스_가계부_2026_고도화.xlsm](references/budgetbook-2026/테트리스_가계부_2026_고도화.xlsm)을 Excel 운영 기준본으로 보관합니다. 2026-10-13까지의 RAW 2,452건과 월별 계산기·예비비·WRAP 잔액을 포함하며, 첨부 파일을 재저장하지 않고 그대로 추가했습니다.

네 파일의 역할, 회계 기준, 독립 대조 결과와 다음 수정 시 연결할 항목은 [가계부 파일 분석·인계](references/budgetbook-2026/가계부_파일분석_인계.md)에 정리했고, 수치 대조 결과는 [audit.json](references/budgetbook-2026/audit.json)에 있습니다.

이 Excel 기준본은 아래 iOS·웹 앱의 2026-10-05 초기 스냅샷과 별도로 관리합니다. 앱의 운영 데이터 이관은 후속 작업입니다.

## 이번 구현

- 거래 입력·수정·삭제와 기기 파일 저장. 성공적으로 저장한 뒤 화면·결산·잔액을 갱신합니다.
- 이번달 **비고정비·고정비·비예비비·예비비 사용**, 실제 확정 결산과 예상 포함 결산, 일별 거래와 검색.
- 비고정비 상세는 최신 날짜부터 날짜·요일·일 합계와 해당 거래를 한 묶음으로 표시합니다. 거래는 분류/세부 분류, 내용·메모/결제수단, 금액 순서이며 눌러 상세 확인·수정합니다. 날짜 미확인 거래는 마지막 묶음에 표시합니다.
- 기록은 표시된 거래의 날짜별 확정 개인 수입·소비 합계를 보여줍니다. 검색 결과에 맞춰 합계도 갱신하며 환급·적립·이체·카드 납부·공동 거래는 내역에만 표시합니다. 설정의 예상·계획은 수입/고정비/예비비 종류별 등록 계획액과 항목을 접어 보고 수정할 수 있습니다. 잔액의 ‘WRAP 잔액 구성’은 같은 WRAP 계좌의 생활비/목적자금 구분입니다.
- 이번달 상단의 이전/다음 달 화살표로 바로 조회월을 전환합니다. 가운데 월 이름을 눌러 직접 월을 선택하는 기능도 유지합니다. 연도 경계를 처리하고 선택한 날짜가 다음 달에 없으면 그달 마지막 날로 조정합니다. 조회월 전환은 원장·잔액을 변경하지 않습니다.
- 예상 월급·고정비를 실제 거래와 연결하여 대체. 설정에서 월별 예상 수입·고정비·예비비 적립계획을 추가·수정합니다. 계획은 실제 잔액을 늘리지 않습니다.
- 예비비 실제적립·직접 사용·생활비 환입, 공동계좌 납입, 투자금 적립, 카드대금 납부, 계좌 이동, 환급·정산, 보류 기록.
- 생활비·목적자금 간 이동과 외부 출금을 구분하는 WRAP 원장. 일반 계좌·카드 잔액은 WRAP 총잔액에 합치지 않습니다.
- JSON 백업·검증·복원. 복원 전 거래 수와 WRAP 잔액을 보여주고 교체를 확인합니다. 기기 내 이전 저장본 확인도 제공합니다.
- 원본 RAW **2,366건**을 검색 가능한 읽기 전용 보관함과 백업에 보존. 운영 이관과 연결한 범위는 **2026년 10월 45건**입니다.

## Mac에서 실행

1. `ios/TetrisBudget.xcodeproj`를 Xcode에서 엽니다.
2. `TetrisBudget` 스킴, **iPhone 17 Pro Max 시뮬레이터**를 선택하고 Run(⌘R)을 누릅니다.
3. 실기기는 Signing & Capabilities에서 본인의 Team과 고유 Bundle Identifier를 설정하고, iPhone을 연결해 Run합니다. 기기가 안내하는 Developer Mode 설정을 따릅니다.
4. Test(⌘U)로 `TetrisBudgetTests`의 네이티브 검증 5개를 실행합니다.

Glass API 컴파일에는 **Xcode 26 이상 SDK**가 필요합니다. iOS 27 실기기 확인에는 해당 기기를 지원하는 Xcode/SDK가 필요합니다. 최소 OS는 iOS 17이며, iOS 26 미만에서는 표준 material을 표시합니다. 네트워크 서버, 외부 런타임, npm 설치가 앱 실행에 필요하지 않습니다. 앱 아이콘·배포 서명·TestFlight 설정은 후속 범위입니다.

**현재 환경은 Linux이므로 Xcode 빌드와 iPhone 실행, 네이티브 XCTest 5개는 아직 실행하지 못했습니다.** 아래의 회계 검증 및 문법·리소스 점검을 네이티브 실행 성공으로 해석하지 마세요. 제공 파일은 설치된 앱이나 서명된 IPA가 아니라 실행·검토용 Xcode 프로젝트입니다.

## 데이터와 계산

첫 실행 시 2026-10-05까지의 운영 데이터를 기기에 복사하고 2026년 10월을 표시합니다. 초기 예상 총수입 **2,780,230원**, 지출·적립 **1,584,335원**, 남는 돈 **1,195,895원**, WRAP **8,480,881원**을 재현합니다. 월급 2,776,050원은 예상입니다. 확정 기록 기준으로는 수입 4,180원, 지출·적립 336,280원이며, 미확인 고정비는 확정 합계에서 제외합니다.

비고정비 286,580원은 담배·선물·일회성 전자를 포함한 19건입니다. 두끼 11,900원은 계좌 현금성 지출인 비예비비에 표시하면서 비고정비에 한 번만 반영합니다. 공동계좌 이후 소비·이자·캐시백은 개인 소비·수입에 다시 합산하지 않습니다.

수입·지출은 원 단위 정수로 계산합니다. 예비비는 실제 적립과 사용을 분리하고 사용한 달에 소비를 반영합니다. 카드대금은 연결된 카드 사용 거래의 소비를 반복하지 않고 출금만 반영합니다. 환급·정산은 수입보다 본인부담 차감으로 처리하며, 이미 순액으로 기록한 지출의 정산을 다시 차감하지 않습니다. 다른 달 정산은 귀속 월을 직접 지정해야 합니다. 대조 차이를 자동으로 이자로 만들지 않습니다.

원본 Excel의 예상 항목과 표시값을 가져왔지만, 과거 전체 결산과 모든 분류의 재이관·재검증을 완료한 것은 아닙니다. 과거 월은 **운영 결산 미이관**이라고 표시하며 원문을 열 수 있습니다. 새로운 거래와 예상 항목은 해당 월에서 계산합니다. WRAP·예비비 잔액은 월별 과거 잔액이 아닌 **전체 운영 기록 기준**입니다.

테트리스 원본 표시값을 보존합니다. 거래나 예상·계획이 바뀌면 월 테트리스 결산을 **검토 대기**로 표시합니다. 새 거래에 수동 표시 금액은 저장할 수 있지만, 임의의 전역 올림·반올림 규칙을 만들지 않습니다.

## 저장과 백업

기기 `Application Support/TetrisBudget/ledger-v1.json`에 atomic 쓰기와 iOS 파일 보호를 적용하도록 구현했습니다. 저장 실패 시 기존 화면 상태를 유지하고 오류를 표시합니다. 원본과 수정·삭제 이력은 유지합니다. 직전 저장본과 복원 직전 파일을 별도로 보관하며, 손상 파일을 발견해도 초기 데이터로 자동 덮어쓰지 않습니다.

설정의 **백업 파일 저장**은 거래·원본·수정 이력·이름 설정을 포함한 JSON을 Files로 내보냅니다. **엑셀·JSON 파일 가져오기**는 32MB 이하의 XLSX/XLS 거래표를 검토한 뒤 새 거래를 추가하거나, JSON 전체 백업을 검증한 뒤 데이터를 교체합니다. 외부 파일 백업 전에 최신 이름 설정도 포함합니다. 평소 이름·밀도·투명도 설정은 UserDefaults에 저장합니다.

앱 계산은 내장 JavaScriptCore가 번들 `ledger-engine.js`를 실행합니다. 같은 파일을 Node 테스트에서 실행하여 계산을 별도 구현한 테스트용 모듈로 대체하지 않았습니다. 입력은 구조화 JSON으로 전달하며 사용자 문자열을 코드로 실행하지 않습니다.

## 이어서 개발할 범위

엑셀의 과거 월 전체 결산·잔액·예비비 계획 자동 이관, 고정비 자동 반복, 청구서 단위 카드대금 배분·할부 규칙, 거래 간 복잡한 부분 정산·연결, 테트리스 표시 규칙, 앱 아이콘 및 iPhone 렌더링·성능 확인입니다. 예비비 사용은 현재 목적자금 직접 지급 기준이며, 카드 결제와 목적자금 지급을 자동으로 연결하는 기능은 후속 범위입니다.

`design/preview.html`과 디자인 01/02 ZIP은 이전 디자인 검토용으로 유지했습니다. 이전 디자인은 회계 기능을 연결하지 않은 디자인 검토 화면입니다. 원본 Excel·인계 파일은 수정하지 않았습니다.

미리보기 주소: https://tetris-budget-functional-20261006.devcmy136.chatgpt.site

비공개 Sites 화면의 원본은 `preview-site/dist/index.html`이며, 본인만 접근하는 주소로 제공합니다. 화면의 초기 데이터는 iOS와 같은 2026년 10월 운영 45건 및 읽기 전용 RAW 2,366건입니다. 웹 수정본은 이 브라우저의 localStorage에 저장하며 iPhone 파일과 자동 동기화하지 않습니다. 저장소 접근이 제한된 브라우저에서는 현재 화면에서만 유지하고 그 상태를 표시합니다. 설정에서 JSON으로 내보내고 다시 가져올 수 있습니다. 초기화는 테스트 화면의 저장본만 바꿉니다.

상단 ⓘ 또는 데스크톱 오른쪽 예시를 누르면 입력 화면이 채워집니다. 거래 저장을 누른 뒤 이번달·예비비·잔액에서 계산 변화를 확인하세요. `playground/verification.json`에 16개 브라우저 시나리오 결과가 있습니다. 관리형 Chromium의 페이지 이동 제한으로 HTML을 직접 주입하여 검증했고, localStorage는 명시적인 테스트 대역을 사용했습니다. 저장·새 화면 복원 경로를 검증했으나 실제 브라우저 디스크 유지 여부는 아직 검증하지 못했습니다. 네이티브 SwiftUI·Liquid Glass·키보드·기기 파일 보호 검증은 포함하지 않습니다.

웹 파일 재생성: `python playground/build.py`. 브라우저 테스트: `python playground/verify.py` (Chromium 및 Playwright 필요). 스크린샷은 `playground/screenshots/`에 있습니다.

## 엑셀 거래 가져오기

설정 → 엑셀·JSON 파일 가져오기 → `.xlsx` 또는 `.xls` 선택 → 행별 검토 → N건 추가하기. 기존 테트리스 가계부의 RAW 시트와 편한가계부 거래표를 지원합니다. 일시(또는 월)·자산·내용·금액(KRW)/금액·수입/지출 열을 인식하며, 선택할 수 있는 거래 시트가 여러 개면 가져올 시트를 고릅니다. XLSX는 압축 해제 기준 64MB까지, 파일은 32MB까지 지원합니다.

엑셀은 현재 거래에 추가합니다. 기존 결산·기준 잔액·이름 설정을 전체 교체하지 않습니다. 일시·계좌·내용·원금액·종류와 동일 행 수를 대조하여 중복을 제외하고, 이전 사용자 수정·삭제도 보존합니다. 같은 거래로 보이는데 금액이 달라진 행은 자동 선택을 해제합니다. 같은 금액의 기존 거래에서 분류·본인부담만 바뀌면 기존값을 유지하고 검토 이유를 표시합니다.

고정비는 상태를 확인하고 해당 월의 예상 항목을 선택하여 실제로 대체할 수 있습니다. 카드대금·환급·캐시백·이체·목적자금·기준일 이전 WRAP 거래는 보류로 가져와 결산과 잔액에서 제외하며, 기록 수정에서 연결과 거래 종류를 직접 확인합니다. 계좌 현금 지출은 고정/비고정비에 한 번만 반영합니다. 명시된 원 단위 본인부담을 사용하면 순액 여부와 원금액을 함께 보존합니다. 잘못된 날짜·소수점 원 금액·빈 수식 결과는 행별 오류로 제외합니다. 수식과 매크로는 실행하지 않고 엑셀에 저장된 결과를 읽습니다.

가져온 원본 행은 전체 RAW 보관함과 JSON 백업에 보존하며, 거래를 수정·삭제해도 원문은 유지합니다. 월별 결산·예비비·잔액 시트는 자동 계산하거나 이관하지 않습니다. 새로운 형식의 표는 열 이름을 확인해야 하며, JSON은 기존처럼 전체 데이터 복원에 사용합니다.

`core/excel-importer.js`와 SheetJS CE 0.20.3을 웹과 iOS JavaScriptCore에서 동일하게 사용합니다. 런타임 CDN/서버 요청 없이 기기에서 읽습니다. 검증: `verification/excel-tests.tap`의 18개 시나리오, 기존 회계 34개, 브라우저 22개 통과. JavaScriptCore와 같은 제한된 JS 환경의 base64 읽기/검토/가져오기도 검증했지만, 실제 iOS SDK 빌드 및 기기 실행은 미검증입니다. 라이브러리 출처와 라이선스는 `core/vendor/NOTICE.json`, `SheetJS-LICENSE.txt`에 있습니다.

검증 명령: `node --test --test-isolation=none tests/excel-importer.test.js`. `tests/fixtures`는 합성 거래 파일이며 실제 개인 거래를 포함하지 않습니다.
