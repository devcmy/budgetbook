# 테트리스 가계부

엑셀 가계부를 다듬고 검증한 뒤 그 계산 규칙과 데이터를 앱으로 이관하는 개인 프로젝트입니다. 작업·커밋·푸시는 `main` 브랜치에서 진행합니다.

| 폴더 | 내용 |
|---|---|
| [excelWork](excelWork/README.md) | 고도화 XLSM, 참고용 원본, 분석·검증 자료와 엑셀 작업 이력 |
| [app](app/README.md) | iOS 프로젝트, 공유 회계 엔진, 디자인·웹 미리보기, 빌드 스크립트와 테스트 |

현재 엑셀 기준본은 [테트리스_가계부_2026_고도화.xlsm](excelWork/테트리스_가계부_2026_고도화.xlsm)이며, 파일 구조와 계산 기준은 [엑셀 분석·인계](excelWork/가계부_파일분석_인계.md)에 정리되어 있습니다.

앱 실행·검증 명령은 [앱 README](app/README.md)를 참고하세요. 앱의 초기 운영 데이터는 2026-10-05 스냅샷으로, 엑셀 최신 기준본의 이관은 후속 작업입니다.

루트의 `.gitignore`는 두 작업 폴더에 공통으로 적용합니다. 기존 원본과 작업 이력을 보존하고, 엑셀 검증이 확정된 뒤 앱 개발로 이어갑니다.
